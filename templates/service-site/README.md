# Service site template

Starter location for future client websites.

The intended flow is to copy this template into `sites/<client-slug>`, then customize:

- Package name
- Cloudflare Pages project name
- Locale configuration
- Brand tokens
- Content model
- Page sections
- Deployment settings

This template is intentionally empty for now. It should be populated after the first Vicino marketing site establishes the base layouts, sections, i18n conventions, and deployment workflow.
